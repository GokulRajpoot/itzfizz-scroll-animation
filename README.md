# Itzfizz Scroll-Driven Hero

A React + Tailwind + GSAP hero animation prototype.

## Run locally
1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed by Vite.

## Build
Run `npm run build`. The production files are created in `dist/`.

## Notes
- The car is an original inline SVG illustration, so no external image asset is required.
- GSAP ScrollTrigger ties the car movement and orbit rotation to scroll progress.
- Replace the sample metrics and copy with your own content if desired.
- Before submission, test the experience on mobile and compare the motion against the reference.
